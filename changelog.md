# Changelog

All notable changes to the Export URLs and Meta plugin will be documented in this file.

## [1.0.0] - 2025-06-02

### Added
- Complete refactoring to a class-based architecture
- Support for multiple SEO plugins (Yoast SEO, Rank Math, SEOPress, All in One SEO Pack, The SEO Framework)
- Admin interface for selecting content to export
- CSV export functionality with proper UTF-8 encoding
- Input validation and security measures
- Internationalization support
- Proper error handling and user feedback
- WordPress coding standards compliance

### Changed
- Improved code organization and maintainability
- Better separation of concerns between components
- Enhanced error handling and logging
- Updated documentation

### Fixed
- Various bugs and issues from the previous version
- Security vulnerabilities
- Compatibility with latest WordPress versions


## Version 0.0.10

- Added support for Rank Math SEO
- Option to include homepage if “Your latest posts” is used
- Support for post category pages in addition to product categories
- Stores user export settings and cleans up on uninstall
- Various minor fixes and performance improvements

## Version 0.0.3

- Added error handling for forms with no selected post types
- Improved Yoast SEO meta title handling for pages, posts, and products

## Version 0.0.2

- Fixed CSV generation bugs
- Added support for WooCommerce product categories

## Version 0.0.1

- Initial release
